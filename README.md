📘 作品説明
この作品は、専門学校2年生前期の学科連携プロジェクトとして制作された3Dアドベンチャーゲームです。
プレイヤーは「少年」を操作しながらステージの謎を解き、視力を失った「少女」のために冒険を進めていきます。
本作品は東京ゲームショウへの出展を目指して開発されました。

🧩 コンセプト
このプロジェクトでは、基底クラス設計やIK（インバース・キネマティクス）を用いたインタラクティブ機能の実装を通じて、プレイヤーに没入感のある体験を届けることを目指しました。

今後は、

状態遷移の複雑化への対応

動的な環境変化へのリアクション強化

再利用性・拡張性の高いコード設計

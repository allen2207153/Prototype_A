📘 作品説明
この作品は、専門学校2年生前期の学科連携プロジェクトとして制作された3Dアドベンチャーゲームです。
プレイヤーは「少年」を操作しながらステージの謎を解き、視力を失った「少女」のために冒険を進めていきます。
本作品は東京ゲームショウへの出展を目指して開発されました。

🧩 コンセプト
このプロジェクトでは、基底クラス設計やIK（インバース・キネマティクス）を用いたインタラクティブ機能の実装を通じて、プレイヤーに没入感のある体験を届けることを目指しました。

＃担当箇所の詳細
私は本作品において、主に以下の要素の設計と実装を担当しました。

🔧 基底クラス設計（キャラクター制御）
プレイヤーとNPCの共通機能を抽象化した基底クラスBCharaを設計し、移動・状態遷移・アニメーション制御の共通処理を集約。

派生クラスPlayerMovementでは、Move()による移動制御と**Think()による状態遷移管理**を分離。これにより、仕様変更時の影響範囲を最小限に抑え、チーム全体での開発効率を向上。

今後はステートパターンを導入し、複雑化する状態管理の分離・再利用性の向上を目指しています。

✋ インタラクティブ機能の実装
手をつなぐシステムでは、IK（Inverse Kinematics）を用いてキャラクターの手・指の動きをリアルタイム補正。固定アニメーションを用いず、自然な感情表現と安心感の演出を実現。

地形や障害物に応じた動的移動制御（NavMeshやRaycast）の実装検討も進行中。

感圧板ギミックでは、抽象クラスPressurePlateを通じて、機能の再利用性を確保。状態ごとの処理分離に向けてステートマシン導入を想定。

🎞 環境アニメーション（設計のみ）
未実装ながら、壁に近づいた際にキャラの手が自然に添えられるシステムなど、プロシージャルアニメーションの設計も担当。

状態遷移ロジックとIKターゲット制御の複雑さを認識し、今後の実装優先度に基づく改良計画を策定中。


今後は、

状態遷移の複雑化への対応

動的な環境変化へのリアクション強化

再利用性・拡張性の高いコード設計

といった面での改良を進め、より高度なゲームシステムの構築を目指します。
